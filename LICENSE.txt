▌ 1. 授权范围

本软件 SolPress（以下称"本软件"）由 hao@xiaokuba.com 个人开发并维护。
本软件采用**朋友圈定向授权**方式，仅授权给开发者明确签发 license 的指定用户使用。

每份 license 通过 Ed25519 数字签名 + 你 Mac 的硬件 UUID（IOPlatformUUID）
绑定，**不可转让到其它机器**。

▌ 2. 你能做什么

  ✓ 在签发 license 绑定的那台 Mac 上自由使用本软件
  ✓ 用本软件输出 PDF / PNG / JPG 印刷文件，文件版权归你所有
  ✓ 把 SolPress.dmg 安装包分享给朋友（DMG 公开下载）

▌ 3. 你不能做什么

  ✗ 把你收到的 license-XXX.json 文件分享给其他任何人
    （技术上也跑不了，因为绑定了你的硬件 UUID）
  ✗ 反编译 / 修改 / 二次分发本软件的二进制
  ✗ 移除或绕过 license 验证机制
  ✗ 把本软件作为商品转售

▌ 4. 隐私 / 数据收集

本软件**不收集任何个人数据，不联网上报任何信息**。

例外（仅本地使用，从不离开你的 Mac）：

  · IOPlatformUUID（机器硬件 UUID）— 仅用于本地 license 验证。
    license JSON 内含该 UUID。
  · 你导入的图片 — 通过 macOS 沙盒 Security-Scoped Bookmark 持久化，
    仅本机读取，不上传任何服务器。
  · 偏好设置 / 会话状态 — 写入 macOS 标准 ~/Library/Containers/...
    沙盒目录，不离开本机。

唯一的网络请求：启动时每天最多一次 GitHub Releases API 检查新版本（公开 API，
不传任何个人信息）。可在「设置 → 启动行为 → 启动时检查更新」关闭。

▌ 5. 责任声明

本软件按"现状"提供，无任何明示或暗示的担保（包括适销性、
特定用途适用性、不侵权等）。

开发者不对以下情况承担责任：

  · 印刷输出与预期不符（请送印前先打样验证）
  · 软件 bug 导致的数据丢失（建议导出前另行备份）
  · 自动更新导致的兼容问题（DMG 内附说明可手动降级）

如对印刷质量有严格要求，**强烈建议在每次新模板 / 新偏移调整后先打样 1 张**
再批量送印。

如发现 license 被泄露 / 滥用 / 转让，开发者保留在后续版本中**远程撤销
该 license** 的权利。撤销后该 license 在新版本中无法激活。

▌ 7. 协议变更

本协议可能随版本更新调整，新版本协议会随对应 DMG 内附。继续使用即视为
接受新协议。重大变更会单独邮件通知。
